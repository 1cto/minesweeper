# Game engine is pure functions with injected time and randomness

The game rules live in a framework-free TypeScript module exposed as pure functions over immutable state (`applyAction(game, action) → game`), not as a stateful `Game` class with subscriptions; the pure form is simpler to test-drive and maps directly onto React's `useReducer`. The engine never reads the clock or a global random source: every action carries the current time and Layout generation receives a random source, so all rules, including the timer and Best Times, are deterministic under test. Mouse gestures (pressed Cells, the smiley's "O" face, two-button Chords) belong to the UI, which translates them into engine actions such as Reveal, Flag and Chord; the engine knows nothing about input devices.
